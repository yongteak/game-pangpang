# 「팡팡 프렌즈」 모션 액션 게임 원리 및 수학적 공리 문서

> 본 문서는 **Nintendo Wii Sports / Resort**, **Fruit Ninja (Kinect / VR)**, **Beat Saber**, **Ring Fit Adventure**, **Just Dance**, **레디&루디(Redi & Ludi)** 등 대표 모션 액션 게임들의 게임성과 물리·인식 원리를 분석하고, 이를 본 프로젝트(`src/games.js`, `src/pixiRenderer.js`, `src/tracker.js`)에 직접 적용하기 위한 **7가지 수학적 공리(Axioms)**를 정의합니다.

---

## 1. 대표 모션 액션 게임 메커니즘 벤치마크 분석

| 레퍼런스 게임 | 핵심 액션 메커니즘 | '손맛'을 만드는 숨은 수학/규칙 |
| :--- | :--- | :--- |
| **Fruit Ninja (Kinect/VR)** | 공중 과일 베기 | **속도 게이트(Velocity Gate)** — 손을 가만히 대고 있으면 베어지지 않음. **선분 교차(Swept Segment)**로 빠른 스윙 터널링 방지 + 베기 방향 각도로 반쪽 분리 |
| **Wii Sports Resort (검술/테니스)** | 스윙 강약·방향 반영 | **유휴 상태 감쇠** — 움직이지 않을 땐 궤적과 타격 판정 비활성. 스윙 속도 $\mathbf{v}$가 임계치를 넘을 때만 타격음 + 히트스톱 + 화면 흔들림 발생 |
| **Beat Saber** | 리듬 스윙 & 시각 피드백 | **가산 블렌딩(Additive Bloom)** 궤적은 속도 비례로 밝아지고, 정지 시 즉시 소멸. 베기 순간의 섬광(Slash Flash)으로 공간 인지 극대화 |
| **Ring Fit Adventure** | 반복 운동 에너지 충전 | **왕복 운동량(Oscillation Energy)** — 단순 접촉이 아니라 손을 빠르게 흔드는 운동 에너지의 누적($\sum \|\Delta \mathbf{p}\|$)으로 보스 게이지 차감 |
| **Just Dance / 레디&루디** | 유아용 전신 인식 | **관대한 히트박스 + 노이즈 필터링(EMA)** — 4세의 미세한 흔들림이나 카메라 지터(Jitter)를 무시하고 의도된 큰 동작만 정확히 캐치 |

## 2. 7대 모션 게임 수학적 공리 (Core Axioms)

프레임 $t$에서 플레이어 $k \in \{0, 1\}$ 의 손 좌표를 $\mathbf{p}_{k}(t) = (x, y) \in \mathbb{R}^2$, 직전 프레임과의 시간 간격을 $\Delta t$ 라 하자.

### 공리 1. 운동량 기반 베기 판정 (Velocity-Gated Slash Axiom)
> **"정지된 손은 칼날이 아니다. 움직이는 손만이 사물을 벤다."**

손의 순간 변위 벡터 $\mathbf{u}(t) = \mathbf{p}(t) - \mathbf{p}(t - \Delta t)$ 와 순간 속력 $v(t)$ 를 다음과 같이 정의한다:
$$v(t) = \frac{\|\mathbf{u}(t)\|}{\Delta t}$$

베기(Slash) 판정은 반드시 다음 조건을 만족할 때만 활성화된다:
$$\text{isSlashing}(t) \iff v(t) \ge v_{\min}$$

* $v_{\min}$ (화면 대각선 비율 기준 초당 이동 속도):
  * `slow` (4세): $v_{\min} = 220\text{ px/s}$ (작은 팔 흔들기도 허용하되 정지 시 절대 불가)
  * `normal` (보통): $v_{\min} = 300\text{ px/s}$
  * `fast` (6세): $v_{\min} = 380\text{ px/s}$

---

### 공리 2. 연속 선분-원 교차 판정 (Swept Segment-Circle Intersection)
> **"빠르게 휘둘러도 과일을 통과(터널링)하지 않는다."**

단순 점-원 거리 $\|\mathbf{p}(t) - \mathbf{c}\| \le R$ 대신, 이전 위치 $\mathbf{p}_{0} = \mathbf{p}(t-\Delta t)$ 와 현재 위치 $\mathbf{p}_{1} = \mathbf{p}(t)$ 를 잇는 선분 $\overline{\mathbf{p}_0 \mathbf{p}_1}$ 과 중심 $\mathbf{c}$, 반지름 $R$ 인 오브젝트 사이의 최단 거리를 계산한다:

$$s = \operatorname{clamp}\!\left(\frac{(\mathbf{c} - \mathbf{p}_0) \cdot (\mathbf{p}_1 - \mathbf{p}_0)}{\|\mathbf{p}_1 - \mathbf{p}_0\|^2},\; 0,\; 1\right)$$
$$\mathbf{q} = \mathbf{p}_0 + s(\mathbf{p}_1 - \mathbf{p}_0), \qquad \text{Hit} \iff \text{isSlashing}(t) \;\land\; \|\mathbf{c} - \mathbf{q}\| \le R_{\text{eff}}$$

여기서 $R_{\text{eff}} = R \cdot \gamma_{\text{age}}$ 이며, 유아용 관대 계수 $\gamma_{\text{age}} \in \{1.35, 1.15, 1.0\}$ 를 적용한다.

---

### 공리 3. 유휴 커서 감쇠 및 시각 피드백 (Idle Cursor Attenuation)
> **"움직이지 않는 손 표시 객체는 시야를 방해하지 않도록 스스로 물러난다."**

손의 활성 에너지 $E(t) \in [0, 1]$ 를 지수 감쇠 모델로 추적한다:
$$E(t) = \begin{cases} \min(1,\; E(t-\Delta t) + 6.5\Delta t) & \text{if } v(t) \ge v_{\min} \\ \max(0,\; E(t-\Delta t) - 2.6\Delta t) & \text{otherwise} \end{cases}$$

이에 따라 화면의 손 표시 객체(Halo)와 무지개 궤적(Trail)은 다음과 같이 표현된다:
* **정지/유휴 상태 ($E \to 0$)**:
  * 무지개 궤적(Trail)은 **즉시 소멸** (가만히 있으면 잔상이 남지 않음).
  * 손 커서 링은 **투명도 $\alpha = 0.22$, 크기 $0.65\times$** 의 얇은 점/링으로 수축해 게임 화면을 가리지 않으며 "지금은 대기 상태"임을 전달.
* **활성 스윙 상태 ($E \to 1$)**:
  * 손 커서가 **밝게 점화($\alpha = 0.95$, 크기 $1.15\times$)**되고, 속력에 비례하는 굵기의 가산 블렌딩 무지개 궤적이 펼쳐짐.

---

### 공리 4. 방향성 절단 및 법선 분리 (Directional Cut & Normal Split)
> **"칼질한 각도 그대로 과일이 갈라져야 손맛이 완성된다."**

베기 벡터 $\mathbf{u} = (u_x, u_y)$ 로부터 절단 각도 $\theta = \operatorname{atan2}(u_y, u_x)$ 와 단위 법선 벡터 $\mathbf{n} = (-\sin\theta, \cos\theta)$ 를 구한다:
* **섬광 빔(Slash Flash)** 은 정확히 각도 $\theta$ 방향으로 그어진다.
* 쪼개진 좌/우 과일 조각은 법선 방향 $\pm \mathbf{n}$ 으로 반대 속도 $\mathbf{v}_{\pm} = \pm v_{\text{split}}\mathbf{n} + (0, -v_{\text{pop}}) + 0.15\mathbf{u}$ 를 받아 자연스럽게 갈라지며 회전 낙하한다.

---

### 공리 5. 충격량 기반 탄성 반발 (Impulse-Driven Balloon Volley)
> **"풍선은 손에 '닿아서'가 아니라 '쳐서' 올라간다."**

풍선 배구에서도 정지한 손($v(t) < 0.6\,v_{\min}$)은 풍선을 강하게 치지 못하며, 손을 휘두르거나 머리로 톡 칠 때 손의 속도 벡터를 합성해 반발한다:
$$\mathbf{v}'_{\text{ball}} = \operatorname{normalize}(\mathbf{c}_{\text{ball}} - \mathbf{p}_{\text{hand}}) \cdot v_{\text{base}} + \kappa\,\mathbf{v}_{\text{hand}}$$

---

### 공리 6. 거대 보스 왕복 타격 (Co-op Boss Oscillation Rule)
> **"거대 수박은 손을 대고만 있으면 절대 깨지지 않고, 신나게 흔들어야 깨진다."**

거대 수박 보스 타격은 **공리 1(속도 게이트) + 쿨다운($0.18\text{s}$)** 을 동시에 적용한다. 아이가 보스 위에 손을 올려놓고 멈춰 있으면 타격이 들어가지 않으며, 손을 빠르게 좌우·상하로 흔들어 $v(t) \ge v_{\min}$ 을 만족할 때마다 "퍽!" 타격 + 탄성 찌그러짐 + 화면 흔들림이 누적되어 깨진다.

---

### 공리 7. 얼음 땡 지수이동평균(EMA) 노이즈 필터링
> **"4세 아이의 미세한 흔들림과 카메라 떨림은 '움직임'으로 오판하지 않는다."**

프레임당 총 관절 이동량 $M(t)$ 를 그대로 쓰지 않고 지수이동평균 $\bar{M}(t)$ 로 평활화한다:
$$\bar{M}(t) = 0.25\,M(t) + 0.75\,\bar{M}(t - \Delta t)$$

얼음 페이즈에서는 $\bar{M}(t) < \theta_{\text{freeze}}$ 이면 완벽한 정지로 인정하여 유아가 좌절하지 않도록 설계한다.

---

## 3. UI 투영 비간섭 원칙 (Non-Intrusive Projection Rule)
* **안내 배너 자동 소멸**: `"거대 수박 등장! 힘껏 흔들어 깨기!"` 같은 안내 배너는 아이콘 없이 깔끔한 텍스트로 **3.5초 표시 후 0.45초 동안 투명하게 자동 페이드아웃**되어 절대 게임 오브젝트(수박 얼굴·진행 영역)를 가리지 않는다.
* **중앙 구도 고정**: 보스 오브젝트는 항상 화면 정중앙 $(0.5W, 0.48H)$ 에, 협동 에너지 바는 하단 $(0.5W, 0.84H)$ 에 고정 배치하여 시안과 동일한 안정적 구도를 유지한다.

---

## 4. 온가족 도파민 페이싱 & 종료 조건 공리 (65~80초 기승전결)

1. **과일 팡팡 (3단계 기승전결)**:
   * **1단계 워밍업 (12개)**: 기본 과일 1~2개씩 등장, 속도·리듬 적응.
   * **2단계 과일 소나기 피버 (22초)**: BGM 템포 상승 + 화면 무지개 피버 테두리 오라 + 과일 대량 투하 + **황금 과일(+3점·골드 플래시)** & **무지개 대폭발(화면 내 모든 과일 연쇄 슬라이스 + 히트스톱)**.
   * **3단계 거대 수박 보스 (16타 / 1인 12타)**: 맞을수록 수박이 부풀어 오르며 타격 텍스트(`퍽!`, `쾅!`, `우지끈!`) + 마지막 일격 **0.22초 극적 슬로우모션 히트스톱 + 120개 컨페티 폭풍**.
2. **도파민 증폭 피드백 (Juice Loop)**:
   * **콤보 음계 상승**: 1.5초 이내 연속 타격 시 `3 COMBO!` → `5 SUPER!!` → `9 FEVER!!!` 와 함께 효과음 음계가 상승.
   * **과즙 스플래시 얼룩**: 베는 순간 반투명 과즙이 배경에 튀어 1.6초간 흘러내리며 시각적 쾌감 극대화.
3. **풍선 배구 (25점 협동 랠리)**: 12점 달성 시 **황금 2번 풍선(+2점)** 추가 투하로 2배 텐션 상승.
4. **얼음 땡! (6라운드)**: 라운드마다 BGM 박자가 점진적으로 빨라지며, 마지막 라운드는 **"만세하고 얼음!"** 보너스.
